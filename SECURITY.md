# Security Policy

## Supported Versions

| Version | Supported          |
|:---|:---:|
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, panic/DoS vector, or memory-safety issue in `fast-croniter`, please report it responsibly:

- **GitHub Security Advisories**: Open a private report at [GitHub Advisory Submission](https://github.com/AkashPriyadarshii/fast-croniter/security/advisories/new).
- **Direct Security Contact**: Email `272530059+AkashPriyadarshii@users.noreply.github.com`.

### Submission Guidelines

Please include:
1. Steps to reproduce or a minimal Python script demonstrating the issue.
2. Malformed cron string or date boundary causing unexpected behavior or panic.
3. System environment (OS, architecture, Python version).

Please do not disclose potential vulnerabilities in public GitHub issues before an advisory and remediation release are prepared. Reports are acknowledged within 48 hours.
